# Web TV - Plateforme de Streaming Vidéo

## Description

Web TV est une plateforme de streaming vidéo inspirée de YouTube, permettant aux utilisateurs de regarder, uploader et gérer des vidéos en ligne. Ce projet comprend la gestion complète des bases de données pour stocker les informations des vidéos, des utilisateurs et des commentaires, ainsi qu’une interface utilisateur développée en Python.

## Fonctionnalités principales

- Upload et lecture de vidéos en streaming
- Gestion des utilisateurs (inscription, authentification)
- Système de commentaires et de likes
- Recherche et filtrage des vidéos
- Interface graphique intuitive développée en Python
- Stockage et gestion des données via une base de données relationnelle

## Technologies utilisées

- Python (interface graphique et backend)
- Base de données relationnelle (PostgreSQL / MySQL / SQLite selon implémentation)
- SQL pour la gestion des données
- Librairies Python pour l’interface (ex : Tkinter, PyQt ou Flask pour web)
- Outils de gestion et manipulation des vidéos
